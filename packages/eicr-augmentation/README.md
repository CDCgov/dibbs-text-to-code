## Overview

🚧 Under Construction 🚧

This 'module' is for the process to handle augmenting eICR messages for various applications, such as 'Text-to-code' (TTC), 'ecr-refinement', and 'query-connector'. It exists currently under the DIBBS-TEXT-TO-CODE project and product repo as this will be the first application to leverage the augmentation functionality and is being developed by said same team. The organization of the structures for eICR Augmentation are meant to keep the code and test separate from TTC, so that in the future it can be part of it's own project and repository.
